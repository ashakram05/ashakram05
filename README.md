## Featured work

### 🏥 Federated Learning for Cross-Hospital Disease Prediction

**Final Year Project · In progress**

> Exploring whether hospitals can collaboratively train disease-prediction models without directly sharing patient data.

The project focuses on the challenges that make this problem interesting in practice: **non-IID hospital data, privacy, class imbalance, and meaningful evaluation.**

**Planned research direction**

* Centralized disease-prediction baseline
* Simulated hospital clients
* Non-IID data distribution using Dirichlet partitioning
* Federated Averaging (FedAvg)
* Centralized vs. federated performance
* Differential Privacy experiments
* Recall and ROC-AUC alongside accuracy
* Membership-inference / privacy analysis

**Current status:** Data loading, cleaning, preprocessing, and initial dataset preparation completed. Federated training and privacy experiments are part of the ongoing project.

[**View repository →**](https://github.com/ashakram05/Federated-Learning-for-Cross-Hospital-Disease-Prediction)

### 📊 FlyRank — Content Refresh & Opportunity Scoring

**ML internship / capstone work · Lane 2**

> Building a scoring approach to help prioritize which content opportunities deserve limited reviewer time.

This is currently my strongest example of applied ML work, combining **real-world data constraints with model evaluation and leakage-aware reasoning**.

* Feature engineering from GSC / GA4 metrics, sessions, and AI-related signals
* Defined a future-looking decline proxy rather than relying on a random split
* Logistic Regression and Random Forest baselines
* Precision@K as a ranking-oriented evaluation metric
* Explicit feature-leakage and validation checks
* Action-oriented scoring and reviewer playbook

**Current status:** Core research, data-contract, baseline, modeling, and action-playbook work completed. Validation audit and final capstone synthesis are being finalized.

[**View repository →**](https://github.com/ashakram05/ayeshaAkram-flyrank)
